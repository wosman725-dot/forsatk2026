# Forsatk V2.1

This is a front-end prototype for the request lifecycle.

## Included
- Request validation
- Automatic Request ID: `FST-YYYY-XXXXX`
- Success confirmation
- Local browser storage for testing only
- Payment remains disabled

## Important
Do **not** use localStorage as the production database. V2.2 should add a secure backend/database. Payment status must only be changed after server-side gateway verification.
